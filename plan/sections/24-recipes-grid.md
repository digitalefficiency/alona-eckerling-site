6. **תנועה (טוקנים)**

6. motion (tokens) — Low motion by direction (warm-craft still-calm; magnetic budget ZERO — calm proof plateau, not a peak). Enter: MStagger soft fade-up across tiles in RTL order (top-/right-most first), ~80ms offset, translateY(14px)→0 + opacity 0→1, over --dur-700 with --ease-out-soft — plates-set-down calm, never bouncy. Filter: clicking a sage chip cross-fades the grid with a gentle FLIP-style reflow (entering tiles opacity 0→1 + settle, leaving tiles fade to 0), ~--dur-500, NO scale-bounce; active chip fills sage via a quiet ~150ms color transition. CMS lazy-load/infinite-scroll: new tiles fade in with the same stagger token so pagination feels seamless. Card hover (desktop only): subtle lift (translateY −4px + softened shadow) + image scale ~1.02, --dur-300/--ease-out-soft — a small invitation, not theatrical; touch gets an active-press state. Reduced-motion twin (prefers-reduced-motion, token-gated): all tiles present at once (no stagger/translate), filtering is an INSTANT swap (no reflow animation), no hover lift/scale, chip color instant — nothing hidden, equally proof-carrying. Home noise→quiet signature NOT here (home-only). Tokens: --dur-700, --dur-500, --dur-300, --ease-out-soft, --stagger-80.
